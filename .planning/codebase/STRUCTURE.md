## Directory Purposes

**`src/app/`:**
- Purpose: Application routing and entry points for Next.js App Router
- Contains: `page.tsx`, `layout.tsx`, `globals.css`, and `api/` endpoints
- Key files: `src/app/page.tsx`, `src/app/layout.tsx`, `src/app/globals.css`

**`src/app/api/`:**
- Purpose: Serverless backend endpoints
- Contains: HTTP Route Handlers
- Key files: `src/app/api/chat/route.ts`, `src/app/api/contact/route.ts`

**`src/components/`:**
- Purpose: Visual presentation blocks, interactive modals, and widgets
- Contains: React functional components with TypeScript props
- Key files: `src/components/DigitalTwinChat.tsx`, `src/components/ProjectsSection.tsx`, `src/components/HeroSection.tsx`

**`public/`:**
- Purpose: Public static file serving
- Contains: PDF documents, images, and SVG icons
- Key files: `public/Gourav_Kar_Resume.pdf`, `public/profile.png`

**`.planning/codebase/`:**
- Purpose: Codebase mapping and architectural documentation generated by GSD
- Contains: Analysis documents for technology stack, architecture, conventions, testing, and concerns

## Key File Locations

**Entry Points:**
- `src/app/page.tsx`: Single-page portfolio root assembling sections and modals
- `src/app/layout.tsx`: HTML `<html>` and `<body>` layout container with font and metadata configurations

**Configuration:**
- `package.json`: Dependency manifests and build scripts
- `tsconfig.json`: TypeScript compiler options and alias `@/*`
- `next.config.ts`: Next.js core settings
- `eslint.config.mjs`: ESLint rules
- `postcss.config.mjs`: PostCSS configuration

**Core Logic:**
- `src/app/api/chat/route.ts`: Prompt engineering and multi-model fallback handler for AI Digital Twin
- `src/app/api/contact/route.ts`: Nodemailer transporter setup and HTML email template generation

**Testing:**
- Not detected (No automated test files currently present)

## Naming Conventions

**Files:**
- React Components: PascalCase (`DigitalTwinChat.tsx`, `HeroSection.tsx`)
- Next.js Routes & Config: lowercase / kebab-case (`page.tsx`, `layout.tsx`, `route.ts`, `eslint.config.mjs`)
- Static assets: snake_case or lowercase (`profile.png`, `Gourav_Kar_Resume.pdf`)

**Directories:**
- Feature directories: lowercase (`components`, `app`, `api`, `chat`, `contact`)

## Where to Add New Code

**New Feature / Portfolio Section:**
- Primary code: `src/components/NewSectionName.tsx`
- Registration: Import and render in `src/app/page.tsx`
- Navigation link: Update `src/components/Navbar.tsx` anchors

**New Backend API Route:**
- Implementation: `src/app/api/<endpoint-name>/route.ts`

**Utilities / Shared Helpers:**
- Shared helpers: Create `src/lib/` or `src/utils/` (e.g. `src/lib/utils.ts` for cn/clsx helpers)
